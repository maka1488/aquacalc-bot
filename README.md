# 💧 AquaCalc — Telegram Mini App & Bot для розрахунку води (10 адрес)

Сучасний, зручний та красивий **Telegram Mini App** та супутній **Telegram Бот** для щомісячного підрахунку вартості споживання води по **10 окремих адресах**.

---

## 🌟 Можливості та особливості

- 📍 **10 окремих адрес:** Кожна адреса має власну картку з назвою, попереднім показником лічильника, полем для введення поточного показника та індивідуальними тарифами.
- 🧮 **Подвійний точний розрахунок:**
  $$\text{Споживання} = \text{Поточний показник} - \text{Попередній показник}\ (\text{м}^3)$$
  $$\text{Сума за водопостачання} = \text{Споживання} \times \text{Тариф на водопостачання}\ (\text{грн})$$
  $$\text{Сума за водовідведення} = \text{Споживання} \times \text{Тариф на водовідведення}\ (\text{грн})$$
  $$\text{Разом до сплати} = \text{Водопостачання} + \text{Водовідведення}\ (\text{грн})$$
- 💧 **Окремий вивід двох сум:** Бот та Mini App видають **дві окремі підсумкові суми** (за водопостачання та за водовідведення), а також загальну суму як по кожній окремій адресі, так і загалом за всіма 10 адресами.
- ⚙️ **Гнучкі тарифи:** Ціна за водопостачання та водовідведення різна для адрес і легко змінюється в 1 клік (прямо на картці або у загальному модальному вікні тарифів). Є функція «Швидко встановити один тариф для всіх 10 адрес».
- 🎨 **Преміальний дизайн Telegram Mini App:**
  - Адаптивний інтерфейс у стилі морської хвилі/води (скляні картки glassmorphism, бейджі, анімації).
  - Підтримка темної та світлої теми Telegram.
  - Тактильний відгук (Haptic Feedback) на смартфонах.
  - Миттєвий перерахунок під час набору тексту без перезавантаження сторінки.
  - Попередження про некоректні показники (якщо поточний менший за попередній).
- 🔄 **Закриття періоду / Новий місяць:** Кнопка «Закрити період» автоматично зберігає поточний звіт в історію, переносить поточні показники у попередні та очищує поля для наступного місяця.
- 📜 **Історія нарахувань:** Зберігання та перегляд попередніх розрахунків.
- 🚀 **Відправка в Telegram & Буфер обміну:** Кнопка відправки красиво оформленого чека в чат бота або швидке копіювання в буфер обміну для Viber/SMS.

## 🚀 Як запустити проєкт

### Крок 1. Отримання токена бота в Telegram (1 хвилина)
1. Відкрийте Telegram та знайдіть офіційного бота [@BotFather](https://t.me/BotFather).
2. Надішліть команду `/newbot`.
3. Вкажіть ім'я бота (наприклад, `Мій Водомір`) та юзернейм (наприклад, `my_water_calc_bot`).
4. Скопіюйте отриманий **HTTP API Token** (вигляду `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

### Крок 2. Налаштування файлу `.env`
Відкрийте файл `.env` у папці проєкту та вставте свій токен:
```env
BOT_TOKEN=ваш_токен_від_botfather
PORT=3005
AUTO_TUNNEL=true
```

### Крок 3. Запуск
Просто двічі клікніть на файл **`run.bat`** або виконайте у терміналі:
```bash
node index.js
```

> **Автоматичний HTTPS тунель:**
> Сервер автоматично запустить `cloudflared.exe` та згенерує захищене публічне посилання `https://*.trycloudflare.com`.
> Бот автоматично налаштує кнопку меню (Menu Button) у Telegram, тож Mini App одразу відкриватиметься всередині месенджера!
